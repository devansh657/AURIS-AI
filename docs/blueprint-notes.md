# AURIS Blueprint Notes

This project translates the supplied personal-AI blueprint into AURIS One.

## Name

**AURIS**: **Autonomous Understanding and Reasoning Intelligence System**

## Practical Product Definition

AURIS One is a supervised Windows-based personal intelligence platform that can eventually combine voice, memory, research, code assistance, browser control, file workflows, verification, and permissioned automation.

## Build Order

1. Core supervisor and deterministic policy.
2. Audit log and task state model.
3. Local API and basic dashboard.
4. Push-to-talk voice.
5. Typed tool registry.
6. Filesystem tools inside approved paths.
7. Browser automation with verification.
8. Structured personal memory.
9. Evidence-driven research workflows.
10. Proactive monitoring after the safety kernel is stable.

## Non-Negotiables

- No unrestricted agent prompt.
- No administrator-level controller.
- No secret storage in prompts, logs, or frontend code.
- No sending, publishing, payments, deletion, or password changes without approval.
- No web page, email, or document content can modify AURIS rules or permissions.
- Every important action must be observable, logged, and verified.
