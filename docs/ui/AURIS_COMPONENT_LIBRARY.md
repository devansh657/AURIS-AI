# AURIS Component Library

- IntelligenceBar: identity, device, voice, privacy, alert, and time.
- NavigationRail: functional workspaces and clearly disabled future workers.
- AurisCore: state-driven Canvas 2D intelligence visual.
- Transcript: timestamped user, AURIS, device, warning, and verification entries.
- MissionView: objective, risk, steps, agents, state, and verification.
- DeviceTopology: cloud boundary, local channel, device, permissions, and telemetry.
- ApprovalCard: exact action, target, data, risk, reversibility, reject, approve-once, and either post-approval Windows observation evidence or a signed repair diagnosis, file/line statistics, isolated test gate, and escaped exact diff.
- MemoryCard: content, source, confidence, sensitivity, verification date, and delete.
- CommandDock: native voice, text directive, execute, pause status, and emergency stop.
- DailyCommandCentre: primary mission, priorities, reminders, connector state, risks, and suggested action.
- ProjectWorkspace: project activity, tasks, memories, events, active-context selection, root registration, and exact-root open control.
- ResearchWorkspace: campaign ledger, evidence constellation, capability coverage, and preserved source stream.
- EngineeringWorkspace: selected root registration, repository composition, snapshot identity, component/instruction/manifest map, review signals, verified check history, trusted failing-test repair launcher, proposal/apply/rollback evidence, signed diff review, and explicit execution boundary for untrusted roots.
- DocumentWorkspace: extraction formats, operation history, filename command, and artifact-worker state.
