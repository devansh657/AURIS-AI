# AURIS Spatial Intelligence Design System

AURIS uses a dark operational environment with cyan for active intelligence, teal for trusted device data, green for verified completion, amber for attention and approval, and red only for critical states. Panels use thin technical lines, restrained light emission, square geometry, clear typography, and tabular telemetry.

The central canvas is a state visualisation rather than decoration. Ring speed, segmentation, node count, perimeter colour, and labels map to dormant, listening, understanding, planning, executing, approval, completed, warning, and stopped states.
