# AURIS Screen Map

1. Command: live core, transcript, mission summary, and approved quick operations.
2. Missions: active plan and durable task history.
3. Devices: secure topology, telemetry, and allowlisted capabilities.
4. Memory: project-scoped explicit memory manager.
5. Approvals: sensitive-action authorisation queue.
6. Activity: append-only operational audit.

7. Daily: current operational briefing, schedule, systems, and local risks.
8. Projects: project context, activity, memories, events, root-registration state, and signed project-open control.
9. Research: campaigns, claim/source links, provenance, contradiction status, and definition-of-done coverage.
10. Engineering: selected-project root, repository snapshot, architecture, test surface, and review signals.
11. Documents: supported read-only extraction formats and recent analyses.
12. Integrations: Outlook, OneDrive, and truthful phone-assistant deployment state.

Automations and other unavailable workers remain visibly disabled until their runtime integrations exist.
